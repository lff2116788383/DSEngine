## 分析结论

- 7 张截图均为 1280x720，非黑屏；mean_luma 约 50-70，画面正常。
- 雨/雷暴/雾/雪/落叶的 mean_rgb、mean_luma 与差异对比均出现可见变化，说明天气粒子与光照后处理生效。
- 雪天 bright_ratio 明显高于晴天/雾天，符合新生成的雪花亮粒子。
- 青溪村、黑风寨、幽篁秘谷三图画面差异明显，地图切换不是重复贴图。
- 战斗演示截图与静景差异明显，HUD/战斗状态存在差异；日志同时确认 combo/skill/equip/boss 路径已在 R6 验收覆盖。
